# 유연근무제 신청서 (flexwork-app)

주간 유연근무제 신청서를 작성·인쇄하고 제출 기록을 남기는 로컬 웹앱.
원본 양식: `유연근무제 신청(변경)서` (전능아이티㈜).

## 기능

- **다음 주 자동 입력**: 실행 시 다음 주 월~금 날짜가 자동으로 채워짐.
- **요일별 구분 선택**: `근무 / 공휴일 / 연차(종일) / 연차(오후) / 연차(오전)`.
  - 근무: 출·퇴근 시각 입력 → 점심 1시간 제외한 실근로시간 자동 계산.
  - 공휴일·연차: 1일 8시간 인정.
  - 연차(오후)=오전만 근무, 연차(오전)=오후만 근무.
- **주 40시간 검증**: 합계(계)를 실시간 표시, `40시간 자동 맞춤` 버튼으로 마지막 근무일 종료시각 조정.
- **Word(docx) 생성**: 원본과 동일한 표 형식·글꼴(맑은 고딕)로 `.docx` 다운로드.
- **인쇄**: 브라우저 인쇄(`인쇄` 버튼)로 컴퓨터에 등록된 프린터에 바로 출력.
- **제출 기록**: 저장한 신청서를 날짜·요일별 계획·합계와 함께 조회. 다시 Word 다운로드/삭제 가능.
- **로그인·여러 사용자**: 첫 화면은 로그인. 계정이 없으면 `회원가입` 탭에서 아이디·비밀번호·이름으로 가입.
  사용자마다 기본 정보와 제출 기록이 따로 저장되며 다른 사람 기록은 보이지 않음.
- **로그인 유지**: 한 번 로그인하면 로그아웃할 때까지 유지. 브라우저가 쿠키 수명을 최대 400일로
  제한하므로 페이지를 열 때마다 만료를 다시 400일로 연장함.


## 서버 배포 · 관리자

1. 서버의 프로젝트 폴더에 `.env.local` 작성 (`.env.example` 참고, git에 올라가지 않음):

   ```bash
   ADMIN_USERNAME=원하는아이디   # 영문·숫자·( _ . - ) 3~20자
   ADMIN_PASSWORD=비밀번호       # 6자 이상
   ```

2. `npm install && npm run build && npm start`

- 서버가 시작될 때 이 계정을 관리자로 만들고, 기존 데이터(`data/settings.json`의 기본 정보,
  주인 없는 제출 기록)를 관리자 계정으로 옮김. 서버 로그에 `[flexwork] ...`로 결과 출력.
  재시작해도 중복 생성·중복 이관 없음.
- 관리자 비밀번호는 `ADMIN_PASSWORD`가 기준. 바꾸고 재시작하면 비밀번호 변경 + 기존 로그인 해제.
- 상단 `관리자` 메뉴(`/admin`): 사용자 목록(가입일·제출 기록 수·최근 저장·로그인 기기 수),
  사용자별 제출 기록 보기·Word 다운로드, 비밀번호 초기화, 계정 삭제.

## 데이터

프로젝트 내 간단한 파일 DB(`data/`):

- `data/users.json` — 계정(비밀번호는 scrypt 해시)과 사용자별 기본 정보(업체/부서/생년월일/성명/공동근무시간)
- `data/sessions.json` — 로그인 세션(토큰의 SHA-256 해시만 저장, 만료 없음)
- `data/entries.json` — 제출 기록 (`userId`로 사용자 구분)
- `data/settings.json` — 다중 사용자 이전의 기본 정보. 서버 시작 시 관리자 계정으로 이관된 뒤
  `settings.migrated.json`으로 이름이 바뀜(원본 보존).

> 기존 iCloud의 docx 파일들은 가져오지 않음. 기록은 이 앱에서 저장한 것부터 쌓임.

## 양식 규칙 (원본 분석 결과)

- 시간 열(합산) = 근무일 `종료−시작−1시간(점심)`, 공휴일/연차 = 8시간 고정.
- 주간 계 = 40시간.
- 시간대 셀 표기: 근무 `09:00 ~18:00`, 공휴일 `공휴일`, 연차종일 `휴가`,
  연차오후 `09:00 ~13:00, 오후 반차`, 연차오전 `13:00 ~18:00, 오전 반차`.

## 스택

Next.js 15 (App Router, TypeScript) · `docx` (서버 생성) · 파일 기반 JSON DB · 브라우저 인쇄.
