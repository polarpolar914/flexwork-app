# 유연근무제 신청서 (flexwork-app)

주간 유연근무제 신청서를 작성·인쇄하고 제출 기록을 남기는 **단일 계정** 로컬 웹앱.
Hiworks 근태에서 이번 주 실제 출·퇴근 기록을 불러와 자동으로 채울 수 있다.
원본 양식: `유연근무제 신청(변경)서` (전능아이티㈜).

## 기능

- **주 선택 자동 입력**: 이번 주 / 다음 주 월~금 날짜 자동 채움.
- **Hiworks 자동 불러오기**: "이번 주" 선택 시 Hiworks 근태에 로그인해 실제 근무시간을 반영
  (아래 [Hiworks 연동](#hiworks-연동) 참고).
- **요일별 구분**: `근무 / 공휴일 / 연차(종일) / 연차(오후) / 연차(오전)`.
  - 근무: 출·퇴근 시각 → 점심 1시간 제외 실근로 자동 계산.
  - 공휴일·연차: 1일 8시간 인정. 연차(오후)=오전만 근무, 연차(오전)=오후만 근무.
- **주 40시간 검증**: 합계 실시간 표시 + `40시간 자동 맞춤` 버튼.
- **Word(docx) 다운로드 / 인쇄 / 제출 기록** 저장·조회.

## 요구사항

- Node.js 18.18 이상 (Next.js 15)

## 초기 설정

1. 의존성 설치:

   ```bash
   npm install
   ```

2. 환경변수 파일 만들기 — 템플릿(`.env.example`)을 복사해 `.env.local` 생성:

   ```bash
   cp .env.example .env.local
   ```

   > `.env.local` 은 비밀 값이 들어가므로 git에 올라가지 않는다(`.gitignore`). 커밋되는
   > 빈 템플릿은 `.env.example` 이다.

3. `.env.local` 값 채우기:

   | 변수 | 필수 | 설명 |
   |---|---|---|
   | `APP_PASSWORD` | ✅ | 앱 로그인 비밀번호(단일 계정). 이 값으로만 로그인. |
   | `HIWORKS_ID` | 자동 불러오기용 | Hiworks 로그인 ID(도메인 포함). 예: `myid@smartdoctor.onhiworks.com` |
   | `HIWORKS_PASSWORD` | 자동 불러오기용 | Hiworks 비밀번호. |
   | `SESSION_SECRET` | 선택 | 세션 쿠키 서명 키. 비우면 `APP_PASSWORD` 로 대체(비번 바꾸면 로그인 해제). |
   | `HIWORKS_COOKIE` | 선택 | 자동 로그인이 막히는 오피스용 폴백 쿠키. |
   | `LOG_RETENTION_DAYS` | 선택 | 로그 보관 일수(기본 14). |

   > 값에 `#` `$` 공백 등 특수문자가 있으면 반드시 작은따옴표로 감싼다:
   > `APP_PASSWORD='p@ss#1'`. (안 감싸면 `#` 뒤가 잘리는 등 오작동)

4. 값을 바꾸면 **서버를 재시작**해야 반영된다.

## 실행

```bash
npm run dev      # 개발: http://localhost:3000
```

프로덕션:

```bash
npm run build && npm start
```

## CLI

웹 없이 터미널에서 같은 기능을 쓸 수 있다. `.env.local` 과 `data/` 를 웹과 그대로 공유한다
(앱 로그인 `APP_PASSWORD` 는 필요 없음).

```bash
npm run cli -- help        # 프로젝트 안에서 실행
npm link                   # 한 번만: 어디서든 `flexwork` 명령으로 실행
```

| 명령 | 설명 |
|---|---|
| `flexwork week [옵션]` | 주간 신청서 작성/미리보기 (기본: 다음 주). 같은 주 저장본이 있으면 거기서 시작 |
| `flexwork hiworks [--week this] [--raw]` | Hiworks 근태 조회 |
| `flexwork list` / `show <id\|날짜>` | 제출 기록 목록 / 상세 |
| `flexwork docx <id\|날짜> [-o 파일]` | 제출 기록을 Word 로 저장 |
| `flexwork delete <id\|날짜> [--yes]` | 제출 기록 삭제 |
| `flexwork settings` / `settings set name=홍길동 ...` | 기본 정보 보기 / 수정 |

`week` 옵션: `--week this|next|YYYY-MM-DD`, `--day <요일>=<값>`(여러 번), `--hiworks`/`--no-hiworks`
(이번 주면 기본 on), `--balance`(40시간 자동 맞춤), `--apply-date`, `--fresh`, `--save`, `--docx [파일|디렉터리]`.

`--day` 값: `09:30-18:20`(근무) · `holiday[:문구]` · `leave`(연차 종일) · `pm[:출근]`(오후 반차) · `am[:퇴근]`(오전 반차).
요일은 `월..금`, `mon..fri`, `1..5`.

```bash
flexwork week --day 수=holiday:개천절 --balance --save --docx ~/Desktop/
flexwork week --week this --balance --docx
```

## Hiworks 연동

앱 로그인 후 **"이번 주"** 를 선택하면 Hiworks 근태에 자동 로그인해 그 주의 실제
출·퇴근 기록을 불러와 요일별 시간을 채운다. 서버가 대신 요청하므로(CORS·쿠키 우회)
브라우저에서 직접 붙여넣을 필요가 없다.

**정규화 규칙**

- **출근**: 09:00~10:00, 10분 단위. 9시 전이면 09:00, 10시 후면 10:00 으로 맞춤(클램프).
- **퇴근**: 17:00~19:00, 10분 단위. 범위 밖이거나 미체크면 버림.
- **미기록/미체크**: 해당 구간(출근 ~10:00, 퇴근 ~19:00)이 **아직 안 지났으면 계획값 유지**
  (저장한 신청서, 없으면 기본 일정). 이미 지났으면 출근 10:00, 퇴근 17:00 기본.
- **그 주 마지막 근무일 퇴근이 안 찍혔으면**: 시점과 무관하게 주 40시간을 채우는 10분 단위
  시각(17:00~19:00)으로 자동 설정.
- 근무일(`근무`)만 대상. 공휴일·연차 등 직접 지정한 모드는 그대로 둔다.

자동 로그인이 막히는 경우(OTP·오피스 정책 등)에는 `HIWORKS_COOKIE` 에 브라우저에서 복사한
세션 쿠키를 넣어 동작시킬 수 있다(`.env.example` 주석 참고, 만료 시 재붙여넣기).

## 로그

- 앱 실행 로그는 `logs/app-YYYY-MM-DD.log` 로 날짜별로 쌓인다(콘솔 출력도 그대로 유지).
- 서버 시작 시와 이후 매일, `LOG_RETENTION_DAYS`(기본 14일)를 넘긴 로그 파일을 **자동 삭제**한다.
- `logs/` 는 git에 올라가지 않는다.

## 데이터

프로젝트 내 간단한 파일 DB(`data/`, git에 올라가지 않음):

- `data/settings.json` — 신청서 공통 기본 정보(업체·부서·생년월일·성명·공동근무시간).
- `data/entries.json` — 제출 기록.

## 양식 규칙 (원본 분석)

- 시간 열(합산) = 근무일 `종료−시작−1시간(점심)`, 공휴일/연차 = 8시간 고정. 주간 계 = 40시간.
- 시간대 셀: 근무 `09:00 ~18:00`, 공휴일 `공휴일`, 연차종일 `휴가`,
  연차오후 `09:00 ~13:00, 오후 반차`, 연차오전 `13:00 ~18:00, 오전 반차`.

## 스택

Next.js 15 (App Router, TypeScript) · `docx`(서버 생성) · 파일 기반 JSON DB · 브라우저 인쇄.

## macOS 메뉴 막대 앱

macOS 13 이상에서 달력 아이콘을 누르면 **네이티브 SwiftUI 패널**이 열린다.
웹페이지를 표시하지 않고, 기존 서버 API로 조회·편집·저장한다.

- **주간 일정**: 이번 주/다음 주 전환, 합계·부족/초과 시간, 요일별 출퇴근·연차·공휴일 편집.
- **빠른 작업**: 40시간 맞춤, Hiworks 근태 불러오기 및 OTP, 신청일 변경, 신청서 저장, 인쇄, Word 저장.
- **제출 기록**: 저장된 신청서 목록·요일별 상세·인쇄·Word 저장·삭제 확인.
- **설정**: 서버 주소와 신청서 기본 정보 편집. 기본 정보는 현재 주에 반영되며 신청서 저장 시 기본값으로 기억한다.

패널을 닫거나 주를 전환해도 작성 중인 입력은 앱 메모리에 유지된다.
서버 새로고침·서버 변경·로그아웃·종료 시에는 입력이 사라질 수 있어 확인한다.
인쇄 버튼은 A4 공식 양식을 macOS 인쇄창으로 보내며, 프린터 또는 PDF 저장을 선택할 수 있다.
WebKit은 화면에 표시하지 않는 인쇄 렌더러로만 사용한다.

### 설치 및 실행

서버·Node.js·`.env.local`·데이터는 앱에 포함되지 않는다. 이 브랜치의 서버 API(`/api/menu-bar`, `/api/menu-bar/print`)를 먼저 배포해야 한다.
서버가 이전 버전이면 주간 조회가 404로 실패하므로 서버와 앱을 함께 업데이트한다.

1. 위 초기 설정을 마치고 웹 서버를 실행한다 (`npm run dev`, 또는 `npm run build` 후 `npm start`).
2. Xcode Command Line Tools가 없다면 `xcode-select --install`로 설치한다.
3. 저장소에서 빌드하고 실행한다.

   ```bash
   npm run test:menu-bar
   npm run macos:test
   npm run macos:build
   npm run macos:open
   ```

`dist/Flexwork.app`을 응용 프로그램 폴더로 복사해 사용할 수도 있다.
현재 Mac의 CPU 아키텍처로 빌드하며 로컬 실행용 임시 서명을 사용한다.
배포용 Developer ID 서명·공증 및 범용 바이너리는 포함하지 않는다.
자동 실행은 macOS **시스템 설정 → 일반 → 로그인 항목**에서 앱을 추가한다.

앱은 Dock 없이 메뉴 막대에 상주한다. 기본 서버는 `http://localhost:3000`이며
설정에서 변경한다. HTTP는 루프백 주소만, 원격 서버는 HTTPS 루트 주소만 지원한다.
기존 `APP_PASSWORD`로 패널에서 로그인한다. 비밀번호·세션은 디스크에 저장하지 않아
앱을 다시 실행하면 로그인해야 한다. 서버 변경 시 세션을 분리하고 재인증한다.
앱 종료는 서버를 종료하지 않는다.

### 검증

`npm run test:menu-bar`는 기존 스케줄 로직을 재사용하는 API 변환을 검증한다.
`npm run macos:test`는 네이티브 주소 검증·인정 시간 계산을 검증한다.
실제 로컬 서버 연동까지 확인하려면 별도 터미널에서 테스트 서버를 실행한다.
개인 Hiworks 계정은 사용하지 않으며 제출 기록이나 기본 정보를 변경하지 않는다.

```bash
APP_PASSWORD=flexwork-native-test npx next dev -H 127.0.0.1 -p 31877
# 다른 터미널에서:
FLEXWORK_TEST_SERVER=http://127.0.0.1:31877 npm run macos:test
```

통합 테스트 범위: 미인증 거부, 로그인, 주간 일정 디코딩, 40시간 맞춤,
Word·인쇄 HTML 응답, 클라이언트별 세션 격리, 로그아웃.

수동 확인:

1. 달력 아이콘 클릭 시 웹뷰 없이 네이티브 패널이 나타나는지 확인한다.
2. 로그인 후 요일·근무 구분·시각을 바꾸고, 주 전환과 패널 재열기 시 입력이 유지되는지 확인한다.
3. 40시간 맞춤·신청서 저장·기록 상세·Word 저장·인쇄창을 확인한다. 삭제 취소 시 기록이 유지되는지 확인한다.
4. Hiworks 실제 계정의 조회·OTP를 확인한다. 외부 계정이 없으면 이 항목은 건너뛴다.
5. 서버 중지·재시작 시 오류 안내와 재시도를 확인한다.
